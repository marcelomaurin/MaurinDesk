# Registro técnico — 11/11/2026

## Objetivo
Iniciar a implementação e manter uma cópia local em C:/projetos/maurinsoft/MaurinDesk,
usando C:/projetos/maurinsoft/CHATGPT para rotinas Pascal reutilizáveis.

## Decisões aplicadas
1. Começar por identidade, presença e consentimento antes de mídia/entrada.
2. Usar PDO SQLite no primeiro backend executável para testar transações sem servidor de banco adicional.
3. Usar WinHTTP no Windows para aproveitar validação TLS nativa, sem dependência OpenSSL no desktop.
4. Proteger credenciais locais com DPAPI; salvar identidade antes do primeiro registro; reutilizar token válido.
5. Manter chamadas de rede em worker; interface não espera requisições na thread visual.
6. Fixar a revisão da biblioteca CHATGPT em dependencies/chatgpt.json.
7. Preservar alterações locais preexistentes em hardware, voice e demo Kinect; nenhum desses arquivos entrou nesta implementação.

## Problemas encontrados e resolução
- Terminal padrão indisponível: acesso local realizado pelo runtime de execução disponível.
- PHP fora do PATH: runtime portátil oficial usado somente para validar a API.
- Constante MOVEFILE_WRITE_THROUGH não exposta pelo Windows unit do FPC: usado valor documentado da flag.
- Colisão de nome local Name com propriedade de formulário: variável renomeada.
- Teste de inicialização: flag --self-test verificada explicitamente por ParamStr; formulário cria e destrói sem abrir uma sessão.
- Automação visual não inicializou: validação limitada a compilação, criação do formulário e integrações por API.
