# Imagens do guia de uso

Capturas da interface do MaurinDesk 0.6.8, preparadas em 14/11/2026 para ilustrar o uso do programa.

As chaves, nomes, arquivos, pastas e situações apresentados são exemplos. As imagens não representam um atendimento real nem comprovam uma conexão com outro computador.

| Imagem | O que mostra |
|---|---|
| [Tela inicial](tela-inicial.png) | A chave própria e o campo para iniciar uma conexão. |
| [Autorizar acesso](autorizar-acesso.png) | As opções de controle, visualização e recusa. |
| [Sessão ativa](sessao-ativa.png) | O atalho de arquivos na janela principal. |
| [Conexão remota](conexao-remota.png) | A barra do visualizador e seus comandos. |
| [Transferir arquivos](transferir-arquivos.png) | Os painéis local e remoto, o destino e a fila. |
| [Configurações](configuracoes.png) | Instalação, início com o Windows e preferências. |
